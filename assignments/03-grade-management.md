# 项目 03：学生成绩管理

**状态：可操作演示 + Java 后端练习题** · 预计练习时间：1–2 天 · 难度：中级

先打开 [在线交互演示](https://xue-moe.github.io/java-web-practice/#grades)，试试成绩录入、修改、删除和统计。演示使用浏览器存储；下方步骤引导你把这些功能实现为 Servlet/JDBC 应用。

## 题目

为一门课程设计成绩登记系统。教师维护学生和课程，录入每位学生的成绩，并查看单科成绩列表和课程统计。

## 必做功能

- 学生档案：学号、姓名、专业/班级。
- 课程档案：课程编号、课程名、学分。
- 成绩：学生、课程、分数、录入时间。
- 支持成绩新增、修改和删除；分数限定在 0–100。
- 按学号或姓名搜索学生；按课程筛选成绩。
- 每门课程显示平均分、最高分、最低分和及格人数。

## 数据关系提示

学生与课程是多对多关系，一名学生修多门课程，一门课程也有多名学生。用成绩表作为关联表：`score(student_id, course_id, score, updated_at)`。同一学生同一课程只能有一条当前成绩记录。

可以先导入 [练习表结构](03-grade-schema.sql)，再自己完成 DAO 和页面。

## 建议实现顺序

1. 先建立学生、课程两张基础表并实现各自列表。
2. 建成绩表，给 `(student_id, course_id)` 添加联合唯一约束和外键。
3. 做成绩录入/修改表单，服务端验证分数范围，并检查学生、课程是否存在。
4. 做课程成绩列表：JOIN 学生表显示姓名和学号。
5. 用 `AVG`、`MAX`、`MIN` 和条件聚合计算统计值；统计结果由 DAO 返回给 Servlet，再由 JSP 展示。
6. 对空课程和没有成绩的情况给出空状态，避免平均分显示为 `NaN` 或空白。

## 伪 SQL 结构

```sql
student(id, student_no, name, class_name)
course(id, course_no, title, credits)
score(id, student_id, course_id, score, updated_at)
```

统计时按课程编号筛选并分组。例如，平均分可以用 `AVG(score)`；及格人数可以用 `SUM(CASE WHEN score >= 60 THEN 1 ELSE 0 END)`。

## 验收清单

- [ ] 一个学生可以录入多门课程成绩，同一门课程不会重复出现两条当前成绩。
- [ ] 分数低于 0 或高于 100 时不能保存。
- [ ] 课程列表可显示成绩明细和统计结果。
- [ ] 修改成绩后，列表和统计值同时更新。
- [ ] 课程尚无成绩时页面正常显示“暂无成绩”。

## 扩展题

1. 增加按分数区间筛选或按成绩排序。
2. 计算课程排名，并说明同分时如何处理并列名次。
3. 导出课程成绩 CSV；不要在导出文件中执行表格公式内容。
4. 加入教师账号，并限制每位教师只能管理自己的课程。
