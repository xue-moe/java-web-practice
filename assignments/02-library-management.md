# 项目 02：图书借阅管理

**状态：可操作演示 + Java 后端练习题** · 预计练习时间：1–2 天 · 难度：入门到中级

先打开 [在线交互演示](https://xue-moe.github.io/HR_Management/#books)，试试新增图书、编辑馆藏数量、借出和归还。演示使用浏览器存储；下方步骤引导你把同样的规则实现为 Servlet/JDBC 应用。

## 题目

为班级图书角制作一个借阅管理系统。管理员维护图书和读者，登记借出与归还，并能查看当前尚未归还的记录。

## 必做功能

- 图书档案：书名、作者、ISBN、总册数。
- 读者档案：姓名、学号或读者编号、手机号。
- 借阅：选择读者和图书，登记借出日期与应还日期。
- 归还：记录实际归还日期；同一本书可被不同读者借阅，但库存不能借成负数。
- 列表：按读者姓名或书名查找；可只看未归还记录。
- 校验：应还日期不能早于借出日期；不能重复归还同一条借阅记录。

## 数据关系提示

至少需要三张表：`book`、`reader`、`loan`。`loan` 保存 `book_id` 和 `reader_id` 外键，以及借出/应还/归还日期。不要把“当前借阅者”直接塞进图书表，因为一本书会经历多次借阅。

可以先导入 [练习表结构](02-library-schema.sql)，再自己完成 DAO 和页面。

## 建议实现顺序

1. 先做图书与读者各自的增删改查，可参考项目 01 的 Bean、DAO、Servlet 分层。
2. 建 `loan` 表，通过外键把借阅记录连到图书和读者。
3. 新增借阅时，在一个数据库事务中检查库存、创建借阅记录并更新可借数量；任一步失败就回滚。
4. 归还时检查记录仍处于“未归还”，写入归还日期并恢复可借数量。
5. 列表查询用 JOIN 一次取出书名和读者姓名，避免在 JSP 里逐条查数据库。
6. 增加关键字和“全部/未归还/已归还”筛选。

## 伪 SQL 结构

```sql
book(id, title, author, isbn, total_copies, available_copies)
reader(id, reader_no, name, phone)
loan(id, book_id, reader_id, borrowed_at, due_at, returned_at)
```

请给 `book.isbn`、`reader.reader_no` 加唯一约束；给 `loan.book_id`、`loan.reader_id` 加外键。`returned_at IS NULL` 表示尚未归还。

## 验收清单

- [ ] 可创建图书和读者，并能在借阅表单中选到它们。
- [ ] 借出一本书后，可借册数减一；库存为零时不能借出。
- [ ] 归还后可借册数加一；同一条记录不能重复归还。
- [ ] 服务器中途出错时，不会出现“借阅记录已创建但库存没变”的半成品状态。
- [ ] 借阅列表能显示书名、读者、借出日期和当前状态。

## 扩展题

1. 显示逾期天数和逾期记录。
2. 为同一 ISBN 管理多个实体副本，并跟踪每本副本的状态。
3. 增加读者借阅上限。
